Nanodimer Simulation Status and Next Steps
==========================================

Current Status
--------------

The repository now has a working Meep/Scheme workflow for qualitative nanorod
dimer exploration on the cluster. The current model is still intentionally
simplified:

- homogeneous background medium, n = 1.28
- normal-incidence source
- fixed Ex polarization by default
- capsule-like Au nanorods, 69 x 24 nm
- no substrate
- no dark-field collection model
- flux-plane proxy spectra, not rigorous scattering cross sections

The earlier invalid cell/PML setup was fixed. Reference fluxes are finite, and
the broadband sweep pipeline now produces physically usable qualitative trends.


Important Interpretation
------------------------

The plotted spectra are normalized flux-plane proxies:

- backscatter proxy = reflected flux / |incident transmitted flux|
- extinction-like proxy = -transmitted differential flux / |incident transmitted flux|

These are useful for trend finding, mode tracking, and design iteration. They
should not be presented as paper-grade dark-field scattering cross sections.

3. Current high-resolution phi sweep

Run parameters:

  theta = 80 deg
  phi = 0, 20, 40, 60, 80, 90, 100, 120, 140, 160, 180 deg
  gap = 0.006 um

Main interpretation:

- The dominant mode is near 0.672 um.
- The 0.672 um mode has strong phi dependence and fits a squared-cosine trend
  well.
- A weak candidate mode near 0.950 um also has a reasonable angular trend, but
  it is much weaker than the 0.672 um mode.
- The previously tracked 0.853 um feature is not a convincing angular mode in
  this run.

Approximate fit summary from the current analysis:

  backscatter, 0.672 um: R2 about 0.973, max about 0.00910
  backscatter, 0.950 um: R2 about 0.886, max about 0.00103
  extinction,  0.672 um: R2 about 0.974, max about 0.00909
  extinction,  0.950 um: R2 about 0.887, max about 0.00103

Visually, the 0.950 um feature is not a strong secondary mode. It is better
described as a weak candidate mode unless higher-quality field plots show a
clear spatial pattern.


Current Bottleneck
------------------

The local Python Meep field plots are too low resolution for confident mode
interpretation. The cluster has old Scheme Meep without Python bindings, so the
current plan is:

1. Run single-wavelength field snapshots on the cluster with Scheme Meep.
2. Save HDF5 field slices from the old Meep run.
3. Copy those HDF5 folders back locally.
4. Plot the slices locally with Python.

This avoids needing Python bindings on the cluster.


Current Field Snapshot Workflow
-------------------------------

Main files:

  simulations/nanodimer/wu-faststart/nanorod_wu_field_snapshot.ctl
  simulations/nanodimer/wu-faststart/run_field_snapshots_background.sh
  simulations/nanodimer/wu-faststart/plot_field_snapshot_h5.py
  simulations/nanodimer/wu-faststart/FIELD_SNAPSHOT_CLUSTER.md

The cluster launcher follows the same execution style as the working broadband
script:

  mpirun -np "$NP" meep-openmpi ...

Smoke test on the cluster:

  cd simulations/nanodimer/wu-faststart
  RES=30 RUN_TIME=5 CASES="40:0.672" ./run_field_snapshots_background.sh

If the smoke test creates HDF5 files in:

  field_phi040_wvl0672

then run the default high-resolution snapshot job:

  NP=16 ./run_field_snapshots_background.sh

The default field snapshot cases are:

  phi = 40 deg,  wavelength = 0.672 um
  phi = 120 deg, wavelength = 0.950 um
  theta = 80 deg
  gap = 0.006 um
  RES = 300
  run_time = 300

The cluster node reports 32 visible cores, so NP=16 is the recommended first
full run. NP=32 may be tested, but NP=16 is a safer balance between speed and
MPI communication overhead.


What To Look For In The Field Snapshots
---------------------------------------

For the 0.672 um / phi=40 case:

- strong near-field concentration around the dimer gap or rod ends
- clear spatial pattern associated with the dominant spectral peak
- reasonable symmetry with the rotated dimer geometry

For the 0.950 um / phi=120 case:

- whether there is a distinct field pattern at all
- whether the field localizes differently than the 0.672 um case
- whether the weak spectral feature has enough spatial structure to justify
  calling it a secondary mode

If the 0.950 um field plot does not show a clear distinct mode, treat it as a
weak spectral shoulder/candidate rather than a robust second resonance.


Next Decisions
--------------

1. First priority: run the cluster field snapshot smoke test.

If it fails, inspect the generated run log and adjust
nanorod_wu_field_snapshot.ctl for that old Meep version.

2. If the smoke test works, run the default NP=16 snapshot job.

After it finishes, copy the field_phi* directories back locally and plot them:

  conda run -n meep-env python plot_field_snapshot_h5.py field_phi040_wvl0672 -o field_phi040_wvl0672.png
  conda run -n meep-env python plot_field_snapshot_h5.py field_phi120_wvl0950 -o field_phi120_wvl0950.png

3. Interpret the spatial fields before adding more expensive runs.

Do not immediately start a larger sweep. The current uncertainty is not the
angle fit; it is whether the weak 0.950 um feature has a meaningful field
pattern.

4. If the 0.950 um pattern is convincing, run crossed field cases:

  CASES="40:0.950 120:0.672" NP=16 ./run_field_snapshots_background.sh

This checks whether the two wavelengths really exchange strength with angle.

5. If the 0.950 um pattern is not convincing, continue design exploration around
the dominant 0.672 um mode and treat the secondary feature as weak.


Working Conclusion
------------------

The simulation workflow is now useful for qualitative nanodimer design
exploration. The current strongest result is a robust, angle-dependent 0.672 um
mode for the theta=80, gap=6 nm dimer. The possible 0.950 um mode is weak and
needs high-resolution field snapshots before it should be interpreted as a
real secondary mode.
