Nanodimer Simulation Status and Next Steps
==========================================

Current Status
--------------

This directory now contains a working Meep-based nanorod dimer workflow. The
original run was invalid because the simulation cell and PML geometry left
essentially no usable monitor area, which produced near-zero reference flux and
unphysical huge case fluxes. That was fixed by increasing the transverse cell
size, reducing PML thickness, and checking that the reference transmission is
finite.

The current validated workflow can:

- Run a homogeneous reference simulation.
- Run nanorod dimer cases with parameterized theta, phi, gap, resolution, and
  spectral sampling.
- Subtract the reference flux.
- Plot normalized backscatter-like and extinction-like proxy spectra.
- Generate stacked spectra similar in style to the Wu et al. figures.

Important interpretation note:

The current plots are normalized flux-plane proxies, not rigorous scattering
cross sections. Specifically:

- backscatter proxy = reflected flux / |incident transmitted flux|
- extinction-like proxy = -transmitted differential flux / |incident transmitted flux|

This is good enough for workflow verification and qualitative trend finding,
but it is not a full dark-field scattering cross-section reproduction.

This is closest to the paper-style orientation/polarization-angle test. It

Current Limitations
-------------------

The current model intentionally remains simplified:

- normal-incidence plane-wave source
- fixed Ex polarization
- homogeneous background medium
- no substrate
- no dark-field illumination or collection geometry
- no closed-box scattering cross-section integration
- simplified capsule nanorod geometry
- gap is still coarse at RES = 200

These limitations are acceptable for verifying the workflow and exploring
qualitative trends. They are not sufficient for exact paper reproduction.


Design Direction
----------------

The initial concept was asymmetric rectangles with a -| orientation. That is a
reasonable design space for broken-symmetry coupling, but rods are probably the
better near-term target if fabrication is important.

Reasons to lean toward rods:

- Nanorods are a common, fabricable plasmonic geometry.
- Rounded ends are more realistic than ideal sharp-corner rectangles.
- Literature comparisons are easier because nanorod dimers are well studied.
- The current workflow already supports rod length, width, gap, theta, and phi.
- Rod dimers should be more forgiving numerically than sharp-corner rectangles.

Asymmetric rectangles may still be useful later if the goal is to engineer
strong symmetry breaking, polarization selectivity, or mode hybridization. But
for a first fabricable design, rods are the more defensible baseline.


Recommended Next Steps
----------------------

1. Treat Wu et al. as a qualitative benchmark, not a strict reproduction.

The goal should be to verify that the simulation pipeline gives stable,
physical trends:

- finite reference flux
- phi symmetry where expected
- orientation-dependent response
- gap-dependent coupling
- resolution convergence

2. Run a gap sweep for the theta = 80 dimer.

The gap is one of the most important physical parameters. Suggested runs:

  GAP = 0.010 um, RES = 200
  GAP = 0.008 um, RES = 300
  GAP = 0.006 um, RES = 400

Use a small angular set first:

  THETA_LIST="80"
  PHI_LIST="0 90 150"

Then expand if the trends look stable.

3. Check resolution convergence.

For one representative case, run:

  RES = 150
  RES = 200
  RES = 300

Track peak wavelength and peak amplitude. The exact amplitude may move, but the
peak position and qualitative trend should begin to stabilize.

4. Add a single-rod reference test.

Before going too far with dimers, add a mode/case for one rod only. Verify:

- longitudinal rod resonance appears in the expected wavelength range
- rotating the rod relative to Ex weakens/strengthens coupling as expected

This is the cleanest validation of material, source, monitors, and plotting.

5. Decide whether full scattering cross section is needed.

If the goal is internal design exploration, the current flux-plane proxies may
be enough.

If the goal becomes quantitative comparison to experiments or papers, add a
closed flux box around the dimer and compute:

  scattering cross section = scattered power / incident intensity

That is a larger modeling upgrade and should come after the simpler trends are
stable.

6. Only add substrate/dark-field geometry if needed.

Substrate and dark-field illumination are important for exact experimental
comparison, but they add complexity. Add them only after:

- the simple homogeneous model is stable
- gap/resolution convergence has been checked
- the design direction is clear

Working Conclusion
------------------

The workflow is now useful for design exploration. The strongest next
verification is not exact paper matching; it is checking that rod dimers show
reasonable symmetry, orientation, gap, and resolution trends. For a fabricable
device concept, continue with rods as the baseline, then revisit asymmetric
rectangles only if rods do not provide enough tunability or symmetry breaking.
